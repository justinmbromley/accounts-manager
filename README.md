# accounts-manager
A GUI C++ Application that allows you to add credentials like usernames, passwords, and emails, stores them securely, and allows you to see them upon logging in. 

A Qt/C++ accounts management application.

## Requirements
- CMake 3.20+
- Qt6
- C++20 compiler

## Configure
```bash
cmake -S . -B build

cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```
